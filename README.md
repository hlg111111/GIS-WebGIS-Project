# 渝北区龙溪街道公园巡查与服务设施可达性 WebGIS

GIS 软件工程课程项目，由何联国完成（学号：2104260065）。项目以重庆市渝北区龙溪街道周边为地图视域，演示 WebGIS 图层管理、要素查询和基础空间分析。

## 直接运行

推荐在 Windows 上双击项目根目录中的 `直接打开WebGIS.html`。也可以双击 `启动并打开系统.bat` 或 `打开系统.url`。

- 普通演示无需安装 Node.js、npm、Git，也无需启动本地服务器。
- 在线街道底图需要网络；网络不可用时，底图可能不显示，本地 GeoJSON 要素和空间分析仍可使用。
- 请将整个项目文件夹一起复制到其他电脑，不要只复制 HTML 文件。

## 功能

- 查看渝北区龙溪街道周边的在线街道底图，支持缩放、拖动和回到初始视图。
- 分别显示或隐藏公园范围、巡查/风险点、应急服务点，并同步更新要素数量。
- 点击地图要素查看属性，选择演示公园范围运行分析。
- 统计范围内的模拟点，并计算到最近演示服务点的 Haversine 球面直线距离。

## 数据与分析边界

地图底图使用 OpenStreetMap.de 提供的 OSM 衍生瓦片，并标注 OpenStreetMap 贡献者。瓦片由在线服务提供，受网络和服务政策影响；请勿高频或批量请求。

本地 GeoJSON 包含 2 个演示公园面、3 个教学巡查/风险点和 3 个教学应急服务点。它们是为课程演示构造的样例，不是实地采集或官方设施数据，也不是法定边界。空间分析结果只用于验证程序逻辑，不可用于真实应急调度、风险判断、导航或设施选址。

坐标使用 WGS84 / EPSG:4326，GeoJSON 坐标顺序为 `[经度, 纬度]`。最近服务点按球面直线距离计算，不代表道路通行或实际可达性。

## 开发与测试

免安装打开不需要 Node.js。若要运行拆分源码的开发服务器，需要 Node.js 18 或更新版本：

```powershell
node scripts/server.mjs
```

然后访问 <http://localhost:8090/>。运行空间逻辑单元测试：

```powershell
node --test tests/空间逻辑测试.mjs
```

## 交付材料

- `src/`：页面、样式、Leaflet 本地库和空间分析代码。
- `data/`：演示 GeoJSON 数据。
- `tests/`：空间逻辑单元测试。
- `scripts/`：可选本地开发服务器。
- `docs/`：需求、设计、部署、开发总结、数据说明、空间逻辑校验、AI 协作日志、提示词记录、AI 错误案例和演示路线。
- `答辩PPT.pptx`：课程答辩演示文稿。
- `系统演示视频.webm`、`演示界面截图.png`：系统演示材料。
