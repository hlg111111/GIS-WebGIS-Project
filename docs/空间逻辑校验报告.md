# 空间逻辑校验报告

## 1. 校验对象

- 文件：`src/spatial.mjs`、`src/app.js`、`data/city-parks.geojson`。
- 坐标系：WGS84 / EPSG:4326，坐标数组约定为 `[经度, 纬度]`。
- 业务空间关系：风险事件 Point 是否落入公园 Polygon；公园质心到服务点 Point 的最近距离。

## 3. 算法检查

1. `pointInPolygon` 使用射线法，测试了内点和外点。
2. `featuresContainingPoints` 只根据几何关系关联，不依赖名称或 ID 偶然一致。
3. `haversineKm` 的输入和输出单位明确为经纬度与公里。
4. `nearestFeature` 对空数组返回 `null`，避免静默选择错误对象。
5. `scorePark` 将风险事件数、高严重度数和距离因素拆开，分级阈值可复核。

## 5. 已知限制

- 质心采用外环顶点平均值，适用于本教学矩形样例，不适合复杂凹多边形。
- 射线法的边界点约定需要生产级 GIS 库进一步确认。
- Haversine 是球面近似，不代替高精度投影距离或测地线服务。
