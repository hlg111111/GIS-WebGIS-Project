# 演示路线说明

建议演示时长：约 1 分钟。对应视频文件为项目根目录的 `系统演示视频.webm`。

1. 双击 `直接打开WebGIS.html`，展示地图位于渝北区龙溪街道周边，并说明在线底图来源；无需安装 Node.js。
2. 指出公园、巡查/风险点、应急服务点三个图层和当前数量。
3. 选择“龙溪街道演示公园范围 A”，运行范围分析，解释 1 个模拟点和约 0.58 km 是构造数据上的演示结果。
4. 依次关闭/开启三个图层，展示地图要素和数量即时变化。
5. 演示缩放、回到龙溪操作，并说明本地示意设施不能用于现实决策。

演示材料使用无旁白录屏；现场可按以上路线补充讲解。
