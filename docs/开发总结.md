## 1. 完成情况

本项目完成一个从需求到部署的 WebGIS 教学实训闭环：需求规格定义业务问题，设计文档拆分数据与算法，代码实现可视化和空间分析，自动化测试验证核心逻辑，部署文档支持本地演示，答辩材料说明取舍与不足。

## 2. 关键收获

- GIS 业务问题必须先转成明确的空间谓词，例如“风险点是否落入公园面”。
- 空间算法的输入顺序、坐标系和边界规则会直接影响业务结论，不能只检查页面是否能显示。
- AI 生成的代码适合加快脚手架和文档产出，但核心空间逻辑需要人工逐行审阅、编写反例和确认阈值。
- 可运行的演示不等于可生产系统，数据来源、权限、异常、审计和部署边界必须写进文档。

## 3. 局限

当前使用脱敏/构造样例数据、自定义 SVG 地图和规则式“GeoAI”建议，没有真实底图、后端数据库、用户认证和模型服务。下一步应引入真实数据授权、PostGIS、正式空间库函数、服务端 API 与 CI/CD。

## 4. 课程分层定位

- 基础层：本项目已经实现小型 WebGIS、GeoJSON、图层控制和空间查询。
- 进阶层：已预留 GeoAI 建议接口，当前采用可审计本地规则模拟。
- 挑战层：尚未实现空间智能体或数字孪生闭环，可作为后续扩展。
