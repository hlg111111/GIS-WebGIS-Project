# 数据来源、空间范围与使用限制

## 地图范围

地图初始中心约为 WGS84（EPSG:4326）经度 106.523、纬度 29.592，展示重庆市渝北区龙溪街道周边的城区街道。视图边界是课程演示范围，不是街道或行政区法定界线。在线底图使用 OpenStreetMap.de 提供的 OSM 衍生地图瓦片，页面同时署名 OpenStreetMap 数据贡献者和瓦片提供方。该地址在本机 `file://` 直接打开测试场景下不会因缺少网页 Referer 而返回标准瓦片服务器的 403；仍需联网，且第三方服务可用性由提供方决定。该服务由捐助资源运行，避免高频请求，遵守其服务限制。项目不批量下载或打包在线瓦片。Leaflet 1.9.4 页面库及其 BSD 2-Clause 许可证随项目放在 `src/`，不依赖外部脚本 CDN。

## 本地 GeoJSON 要素

`data/渝北龙溪演示要素.geojson` 使用 WGS84 经纬度坐标，包含 2 个构造的演示公园多边形、3 个教学巡查/风险点和 3 个教学应急服务点。这些坐标由项目演示构造，不是实地采集、政府设施目录、真实事故记录或测绘边界。名称、弹窗、页面徽标都将其标记为“演示/示意”。它们只用于检查图层开关、点在面内判断、最近点计算等功能，不能用于出行导航、应急调度或真实风险评估。

## 数据验证与局限

- 空间分析使用 GeoJSON 的 `[经度, 纬度]` 顺序；点在面内使用射线法；距离用平均地球半径的 Haversine 球面近似。
- 当前数据只有教学样例，不具备位置精度、完整性、时效性或官方来源证明；“最近服务点”只是在虚构样例中比较直线距离，不是道路网络距离。
- OSM 底图的街道和地名由 OSM 社区维护；在线瓦片可能受网络、服务负载或提供方政策影响。网络不可用时本地要素仍可绘制，但街道底图不会显示。
- 若课程要求真实设施数据，请取得有授权的来源文件，核对坐标系、采集时间、位置精度和许可，再由人工核验后替换演示 GeoJSON，并更新本文件。
