# 需求说明

## 项目目标

交付一个能在浏览器运行的课程 WebGIS 原型，以重庆市渝北区龙溪街道周边作为地图视域，演示地图图层管理、要素查询和基础空间分析。

## 用户与功能需求

1. 用户打开启动脚本后可以访问本机 WebGIS，无需安装 npm 包。
2. 地图应显示龙溪街道周边在线街道底图、初始中心与经纬度坐标。
3. 用户可分别打开/关闭公园范围、巡查/风险点、应急服务点；要素应立即显示/移除，数量同步更新。
4. 用户可点选地图要素查看属性，并能选择演示公园范围。
5. 用户可运行点在面统计和最近服务点球面距离估算，并可缩放、拖动、恢复初始地图。
6. 底图网络失败时，页面提示状态，已加载的本地要素和分析仍能运行。

## 非功能要求与边界

- 面向桌面与窄屏浏览器；本地服务默认监听 127.0.0.1:8090。
- 空间坐标采用 GeoJSON `[经度, 纬度]`、WGS84/EPSG:4326。
- 课程示意点与多边形不可用于真实应急、导航或行政边界表达。
- 底图使用 OpenStreetMap 在线瓦片，需保留署名并遵守其瓦片政策；没有离线瓦片包。

## 验收标准

- 三个图层开关每次均能正确切换地图要素，并同步显示 0 或对应要素数。
- 默认样例各图层数量为公园 2、模拟点 3、服务点 3。
- 示例范围 A 运行分析可统计到 1 个演示点，并返回最近演示服务点及距离。
- 4 项以上空间逻辑单元检查和浏览器端开关/分析交互检查通过。
