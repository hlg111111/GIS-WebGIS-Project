# 测试计划与结果

## 1. 测试范围

| 类型 | 对象 | 方法 | 通过标准 |
|---|---|---|---|
| 单元测试 | 点在面内 | 已知 inside/outside 点 | 结果与预期一致 |
| 单元测试 | Haversine | 0° 经度差 1° | 误差 < 0.2 km |
| 集成测试 | 样例数据空间关联 | 中央公园事件落入关系 | 返回 hazard-001 |
| 集成测试 | 最近服务点 | 中央公园质心 | 返回 service-001 且 < 2 km |
| 规则测试 | 风险分级 | 低/中/高三组输入 | 命中阈值 |
| 结构测试 | 交付包 | `npm run validate` | 必要文件全部存在 |
| 手工验收 | WebGIS 交互 | 图层开关、下拉选择、点击面 | 页面状态正确 |

## 2. 自动化命令

```powershell
npm test
npm run validate
```

## 3. 实测结果

本交付包包含 5 个 Node 测试：

- 点在面内与面外：通过。
- Haversine 距离：通过。
- 中央河滨公园风险事件落入关系：通过。
- 最近服务点确定性：通过。
- 风险阈值可解释性：通过。

浏览器手工测试：启动 `npm start` 后打开 `http://localhost:8080/src/index.html`，应看到地图、5 个公园和图层开关；选择任一公园后右侧面板刷新风险指标。
