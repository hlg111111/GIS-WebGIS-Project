# 运行与部署说明

## 免安装运行（推荐）

1. 将工程文件夹完整复制到 Windows 电脑。
2. 双击 `直接打开WebGIS.html`，或双击 `启动并打开系统.bat` / `打开系统.url`。
3. 无需安装 Node.js、npm、Git 或本地服务器；可用 Edge、Chrome 等浏览器打开。
4. 公园、巡查和服务点要素及空间分析在本地运行；在线 OpenStreetMap 街道底图需要互联网。网络不可用时，地图底色/在线瓦片可能空白，但本地要素和分析仍可运行。

## 可选开发服务器

若要调试拆分后的源码，安装 Node.js 18+，在项目目录运行 `node scripts/server.mjs`，访问 `http://localhost:8090/`。这不是普通使用的必要步骤。服务器只监听本机回环地址，localhost 链接无法直接给其他电脑访问。

## 瓦片使用

工程不打包或预下载地图瓦片，只按当前地图视域请求。底图使用 [OpenStreetMap.de 的 OSM 衍生地图](https://www.openstreetmap.de/)，保留 OSM 贡献者与瓦片服务署名；该服务由捐助资源运行，高频及商业使用有限制，参见 [提供方服务说明](https://www.openstreetmap.de/nutzen/dienste-osm-de/) 和 [OSM 瓦片提供方列表](https://wiki.openstreetmap.org/wiki/Raster_tile_providers)。
