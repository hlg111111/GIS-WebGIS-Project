# 系统设计说明

## 架构

浏览器页面使用原生 HTML/CSS/JavaScript 与 Leaflet 1.9.4 绘制地图。推荐入口 `直接打开WebGIS.html` 将 Leaflet、样式、空间算法与 GeoJSON 样例内嵌，使用 `file://` 即可打开；拆分源码还提供可选的 Node.js 静态服务。外部在线依赖只有 OpenStreetMap 地图瓦片。

## 主要模块

- 页面与样式：`src/index.html`、`src/styles.css`。
- 地图和交互：`src/app.js`，包含图层开关、数量显示、属性弹窗、地图操作及分析调用。
- 空间计算：`src/spatial.js`，包含 Polygon/MultiPolygon 点在面判断、Haversine 距离、最近要素搜索。
- 数据：`data/渝北龙溪演示要素.geojson`，WGS84 坐标的教学样例。
- 可选本地服务：`scripts/server.mjs`，仅供源码调试，根地址重定向到应用页；免安装 HTML 无须该服务。

## 分析流程

用户选择演示公园后，系统过滤巡查/风险 GeoJSON 点，用射线法判断点是否落在面内（孔洞按 GeoJSON 语义排除），再将多边形外环顶点均值作为距离估算原点，用 Haversine 公式计算到每个服务点的大圆近似距离并选最小值。

## 已知限制

最近点按球面直线距离计算，不是道路网络可达性；样例空间要素均为构造数据。在线地图不可用时，本地功能继续工作，但底图区域为空白网格。详见 `数据来源与限制.md`。
