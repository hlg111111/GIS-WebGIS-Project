以下提示词用于说明 AI 参与方式。记录的是“意图”和审查重点，不替代团队的原始聊天导出。

## Prompt-01 需求拆解

```text
请把城市公园应急巡查 WebGIS 拆成用户、功能需求、非功能需求和可验收标准，要求每一条都能映射到代码或测试。
```

## Prompt-02 空间算法

```text
请为 GeoJSON Polygon 与 Point 设计教学版空间分析模块，包含点在面内、Haversine 距离、最近点和可解释风险评分。明确经纬度顺序、坐标系假设和边界风险。
```

## Prompt-03 代码审查

```text
逐行检查这段 GIS 代码是否存在经纬度顺序反转、度量单位错误、空数组崩溃、点面边界误判或把构造数据当成真实数据的风险，并给出最小修复方案。
```

## Prompt-04 测试生成

```text
根据点在面内和最近服务点规则，生成包含 inside、outside、距离单位、空数据和业务阈值的自动化测试。测试断言必须与样例 GeoJSON 的实际坐标关系一致。
```

## Prompt-05 文档与答辩

```text
把项目组织成需求、设计、开发、测试、部署、总结、AI 日志、错误案例和空间逻辑校验报告，明确哪些已实现、哪些只是后续路线。
```
