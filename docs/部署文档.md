# 部署与运行说明

## 1. 环境要求

- Node.js 18 或更高版本。
- Windows PowerShell、macOS Terminal 或 Linux shell。
- 无需数据库，无需额外 npm 依赖。

## 2. 本地部署

```powershell
cd <项目目录>
npm test
npm run validate
npm start
```

默认端口为 8080，可用环境变量覆盖：

```powershell
$env:PORT=8090
npm start
```

浏览器打开 `http://localhost:8080/src/index.html`。

## 3. 静态托管

将 `src/` 和 `data/` 放在同一静态站点根目录，保持 `src/index.html` 对 `../data/city-parks.geojson` 的相对路径。若站点不允许访问上级目录，可把数据复制到 `src/data/`，同时修改 `src/app.js` 的 fetch 路径并重新测试。

## 4. 生产化路线

1. 用 Leaflet 或 OpenLayers 接入经审核的底图服务。
2. 用 PostGIS 管理真实公园、事件和服务点数据。
3. 把规则配置外置，并加入版本号、审计人和生效时间。
4. 将本地 GeoAI 建议替换为经安全评估、脱敏和人工复核的服务。
5. 建立 CI：测试、静态检查、数据模式校验和部署审批通过后再发布。
