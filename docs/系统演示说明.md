# 系统演示脚本

## 3 分钟演示路线

1. 运行 `npm start`，打开 `http://localhost:8080/src/index.html`。
2. 说明地图上的绿色面是公园，红/橙/灰点是风险事件，蓝点是应急服务点。
3. 关闭“风险事件”图层，再打开，展示图层控制不会改变原始数据。
4. 点击“中央河滨公园”，说明系统通过点在面内判断只统计落入范围的事件。
5. 指出右侧结果：中央河滨公园包含 1 个风险事件，最近服务点为中央急救站，系统给出风险分和建议。
6. 切换“东湖湿地公园”，展示同一套算法可以复用到不同对象。
7. 回到代码或测试命令，运行 `npm test`，说明空间逻辑不只依赖页面目测。
8. 打开 `docs/AI错误案例集.md`，说明 AI 生成代码经过人工校验，且记录了错误案例。

## 答辩应主动说明

样例数据不是生产数据，SVG 地图不是正式底图服务，GeoAI 建议是可审计的规则原型。项目的重点是完整经历 GIS 软件生命周期，并把空间正确性、AI 审查和测试部署证据链放进同一仓库。
